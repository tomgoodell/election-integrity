Election Integrity Directory — Backup & Restore

Back up all Airtable tables to a JSON file on your computer, or restore from a previously saved backup. Must be served from the same domain as the app so the /airtable proxy is available.

🔑 Admin password

Required: backup reads the Pending table and restore writes records — both are admin-only. Same password as the app's Admin tab.

📥 Back up database

Downloads a complete snapshot of all five tables — Organizations, OrgTags, Categories, CategoryValues, and Pending — as a timestamped JSON file. Nothing is modified. Takes about 10–15 seconds.

📤 Restore from backup

Choose a backup JSON file created by this tool. The restore will delete all current records in Organizations, OrgTags, and Pending, then recreate them from the backup. Categories and CategoryValues are not touched — their record IDs are stable and the backup data already references them.

⚠ Destructive operation. All current Organizations, OrgTags, and Pending records will be permanently deleted and replaced with the backup data. Consider downloading a fresh backup first.
