Add States to CategoryValues

Automatically finds the States category in Airtable and adds all 50 states plus Washington DC as CategoryValues. Safe to run more than once — existing states are skipped. Must be served from the same domain as the app.

This script will look up your States category, then create one CategoryValue row for each state with the correct CategoryID, CategoryName, CategoryKey, Value, SortOrder, and Active fields all filled in automatically. Takes about 3 minutes.
